# 静的ページのコーディング規約

漫画新刊JPの静的ページ（データベースから生成するページ）を作るときの基準。決まったことはここに書き足す。

## デザインの正

- claude.ai のデザイン（キャンバス）にある各ページのモックアップ。確定版は Google ドライブ「漫画新刊JP」フォルダの「漫画新刊JP_モックアップ一式_2026-10-28.zip」
- 目標はピクセルパーフェクト。モックアップと同じサンプルデータで生成したページを、ヘッドレスブラウザで重ねて差分を取り、ずれをなくす
- モックアップとデザインの不整合（ページ間で作りが違う等）は独断で統一せず、確認してから直す

## ファイル構成

```
templates/            Jinja2 テンプレート（layout.html ＋ ページごと）
static/css/           CSS
static/js/            JavaScript（フレームワークなし）
src/newcomics/build.py  生成処理
dist/                 生成結果（Git には入れない）
tests/visual/         見た目の照合（モックアップとの差分）
```

## ファイルごとの編集可否

| ファイル | 扱い |
| --- | --- |
| templates/・static/・src/ | 編集してよい |
| データベース | 非公開リポジトリ new-comics-data にあり、GitHub Actions が更新する。手で編集しない |
| dist/ | 生成物。直接編集しない |
| dist/index.html（トップページ） | 生成物だが、公開前に必ず運営者の確認を取る |

## ブレイクポイント

- 1段のみ。`@media (max-width: 720px)` でスマホ表示に切り替える（モックアップと同じ）
- それ以外の幅の変化は、モックアップと同じく flex-wrap と flex-basis による折り返しで対応する
- 照合する幅：1280px（PC）、721px／720px（境界）、375px（スマホ）

## HTML

- インデントしない。コメントアウトは入れない
- head の中は関連するタグごとに空行で区切る
- style 属性は使わず、すべて class で指定する
- img の alt は内容を極力簡潔に（書影は「書名 巻数」）。装飾や記号など意味のない画像は空でよい
- 装飾用の SVG には aria-hidden="true" を付ける

## CSS

- インデントしない。セレクタとセレクタの間に空行を入れない。空行はメディアクエリの前後など限定的に
- 各項目の先頭に次の形式のタイトルコメントを書く

```
/* ==========================================================================
タイトル
========================================================================== */
```

- カスタムプロパティ（変数）は使わない
- クラス名は BEM のアンダースコア区切りのみ（例：`book_card`、`book_card__title`、`book_card--final`）。接頭辞（l_ / c_ / p_ / u_）は付けない
- 役割の違う要素は class で区別し、`nth-of-type` など並び順に依存させない
- font-size・margin・padding は px。値はモックアップの数値をそのまま使う

## デザイン基準値

- フォント：Noto Sans JP（400/500/700/900）、Fredoka（500/600/700）。Google Fonts から読み込む
- 本文 14px、行送り 1.6
- 外側の余白 12px、パネル間 12px、パネルの角丸 20px

## 決まったこと

- トップページのメニューも、ほかのページと同じスマホ開閉式にする（モックアップのトップページには開閉ボタンがなかった）
- CSS は static/css/style.css の1ファイルにまとめる
- 公開先はロリポップの new-comics.jp 用の公開フォルダ（独自ドメイン設定の「new-comics.jp」）

## 照合の結果（2026-10-28）

モックアップと同じサンプルデータで生成したページを、1280／721／720／375px で撮影して差分を取り、全13種類で差分0ピクセル。

- 書籍ページのスマホ表示は、スライダーの1画面2冊の状態（実際のモックアップの動き）と照合した
- 検索結果ページの出版社の選択欄は、モックアップの静的書き出しでは「すべて」になっているため、照合時は同じ状態にそろえた

## モックアップにないもの（確認待ち）

- 出版社一覧（/publisher/）・レーベル一覧（/label/）・タグ一覧（/tag/）：既存の部品で仮に作成
- トップの特集欄：記事がないあいだは「特集記事は準備中です。」と表示
